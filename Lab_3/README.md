# Лабораторная работа №3

PyQt5-приложение визуализирует четыре базовых растровых алгоритма:

1. пошаговый алгоритм;
2. ЦДА;
3. алгоритм Брезенхема для отрезка;
4. алгоритм Брезенхема для окружности.

Есть координатные оси, сетка, подписи, автоматический подбор масштаба,
ползунок и кнопки масштабирования, примеры данных и отображение центров пикселей.
Если отрезок или окружность выходят за максимальную видимую область сетки,
приложение показывает предупреждение с допустимыми диапазонами координат.

## Запуск

### Windows

Готовое приложение не требует установленного Python:

```text
main.exe
```

```bash
cd /Users/mikhailpaprotski/vscode/computerGraphicsBSU/Lab_3
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Замеры времени запускаются командой `python benchmark.py`.

Для окружности `x0`, `y0` — координаты центра, `R` — радиус. Целочисленная
точка `(x, y)` привязана к центру соответствующей квадратной ячейки сетки.

## Временные характеристики

Скрипт `benchmark.py` выполняет пять серий адаптивной длительности и выводит
медиану времени. Для отрезков сложность равна
`O(max(|dx|, |dy|))`, для окружности — `O(R)`. Память этой учебной реализации
— `O(n)`, поскольку вычисленные точки сохраняются для визуализации.

## Пример вычислений Брезенхема

Для отрезка `(0, 0) → (5, 3)` получаем `dx=5`, `dy=3`, начальную ошибку
`err=dx-dy=2`. Последовательность пикселей:

```text
(0, 0), (1, 1), (2, 1), (3, 2), (4, 2), (5, 3)
```

На каждом шаге рассчитывается `e2=2*err`; по его сравнению с `-dy` и `dx`
выбирается изменение координат. Подробная таблица вычислений приведена в отчёте.

В исходном PDF нет таблицы вариантов, поэтому для нечётного варианта выполнен
полный обязательный набор из четырёх алгоритмов с произвольными входными
данными.
