# Лабораторная работа №4

Приложение иллюстрирует алгоритмы отсечения отрезков и выпуклого
многоугольника прямоугольным окном.

Реализованы:

- алгоритм Сазерленда-Коэна;
- алгоритм Лианга-Барски;
- алгоритм средней точки;
- алгоритм Сазерленда-Ходжмана для выпуклого многоугольника — часть 2
  нечётного варианта.

## Запуск в Windows

Готовая сборка не требует установленного Python:

```text
main.exe
```

## Запуск из исходников

```bash
cd /Users/mikhailpaprotski/vscode/computerGraphicsBSU/Lab_4
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

## Формат входного файла

```text
n
x1 y1 x2 y2
...
x1 y1 x2 y2
xmin ymin xmax ymax
```

Пример находится в `example_segments.txt`.

## Проверка и замеры

```bash
python -m unittest -v test_algorithms.py
python benchmark.py
```

Синее обозначает отсекающее окно, серое — исходные объекты, красное —
видимую часть после отсечения. Координаты ограничены диапазоном ±10000;
при выходе за него приложение показывает предупреждение.
